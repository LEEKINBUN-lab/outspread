# 便签的生命周期 · 六条轴 + 新手走一遍

交互机（docs/interaction-machine.md）管"这一发按键归谁"。这一页管**一个对象**：一格便签从被造出来到被删掉，它的属性各自能取哪些值、谁有权改它、改完什么必须跟着变、以及有没有进去出不来的死状态。

## 一、六条正交的轴（不是一条流水线）

"生命周期"最容易设计错的地方是把它画成一条线：新建→写字→上色→归档。实际上这几件事**互不相干地各自漂移**，所以按轴组织，每条轴单独问"谁能改／改完必须跟着变什么／有没有死状态"。

| 轴 | 取值 | 谁能改（App 现状） | 改完必须跟着变 | 死状态检查 |
|---|---|---|---|---|
| **内容** | 空 → 有字 → 字超出框 → 图片 → 文件 → 链接 | 双击新建、编辑框、粘贴、拖文件、`outspread patch` | 高度（"便签大小随文字"开着时）、换行按屏上宽度重算 | ⚠ **空是一格能长期停留的状态**：新建后 Esc 只放弃编辑，空格子留在板上并会落盘。已验：`:1543-1546` |
| **颜色** | 无色 → 预设 `"1"`…`"6"` → 自定义 `#RRGGBB` | 右键菜单 6 档＋无色；agent 写 hex | 墨色跟着换档（Radix 12 步）、描边取 7 步、对比度必须仍 ≥4.5:1 | ✅ 校验器会拒非法值（`CanvasValidator.cs:137-148`），且**自定义 hex 不配描边色**（用墨色 30%），不会凭空造第二个 hue |
| **标记** | 无 → `#tag`… → `#due:YYYY-MM-DD`（将来/今天/逾期） | **只有打字这一条路** | 左边缘 2px 色条、侧栏清单、筛选 | ⚠ **屏上零反馈**：写进去的字改了，但没有任何可见结果 ⇒ 用户无法知道"我标成功了没有"。S8 未做 |
| **归属** | 自由 → 在某组内（几何包含）→ 组这一层被选中 / 单枚被选中 | **App 里没有产生组的路径**：只能读 .canvas 里已有的 | 移出框 = 自动脱离；拖组带整组 | ⚠ 双向死状态：既造不出组，也拆不掉组（无成组/拆组命令）。S5/S7 未做 |
| **关系** | 孤立 → 有出边 → 有入边 → 两端都连 | 无（连线不渲染也不产生） | `fromSide/toSide` 落盘、曲线随格子动 | ⚠ 板上那条 `u555555555` link 节点读进来原样保留、屏上不画 ⇒ 关系轴**只在文件里存在** |
| **稳定性** | 可动 → 锁定 | 无 | 锁定的格不许被任何命令搬动，**但必须能被解锁** | ⚠ 未实现。实现时最忌"锁了找不到开锁"——菜单必须始终留着解锁那一项 |

还有一条不属于格子、但决定它生死：**持久轴** 屏上 → 已写盘（400ms 定时器）→ 被外部改过（FileWatcher 0.4s 并入，且这一步可撤销）→ 同步冲突。这条是六条里最完整的，agent 那条路能走通全靠它。

### 从这张表得到的四条不变量（要写成会抛错的测试）

1. **一格从"空"离开只有两种方式**：写出字，或者被回收。按 Esc 取消一次"刚新建、还没写过字"的编辑 ⇒ 那一格应当消失，且**不留下撤销步**（否则 history 里全是空格子的尸体）。
2. **改文字不许动颜色，改颜色不许动文字**：两条 patch 路径必须互不清除对方的字段（规范里它们是同一对象的两个键，一次整体替换就会互相抹掉）。
3. **凡是被写进 `text` 的语法（`#due:`、`#tag`、`@due(…)`、`@tag(…)`），要么有可见效果，要么被明着标成"没认出来"**——不许静默当普通字。`#ff6b6b` 被当成标签、`#due:2026-13-40` 被当成标签，都是这一条的反例（原型里各踩过一次，有 `HEXISH`/`DUE_RE` 两道滤）。新形状多一条：**行内的 `@due(…)` 不生效，但必须照样显示在原处**（不变量在这一条上是"看得见"，不是"起作用"）。
4. **脱离组必须当场可见**：成员是几何包含，把格子拖出框就脱组；这条不许只在数据里成立（用户会以为它还在组里）。

## 二、模拟一个第一次打开它的人

以 `boards/scratch.canvas` 这块演示板为"第一屏"，逐步记"他想干什么 → 实际走到哪 → 卡点"。

| # | 他想 | 现在怎么走 | 判定 |
|---|---|---|---|
| 1 | 记一件事 | 双击空白 → 出现一格并进编辑 | ✅ 走通；但**双击已有格子＝编辑那格**，新手点错位置就会去改到别人的字 |
| 2 | 写完不收尾，先想想 | Esc | ❌ 他以为取消了整件事，实际留下一格空的（不变量 1 破） |
| 3 | 换行 / 收尾 | 回车换行、`Ctrl+Enter` 提交 | ✅ 状态条写了快捷键（`:1482`）；但**点别处也提交**，与"Esc 才放弃"的直觉并存，容易误提交 |
| 4 | 给它上个颜色 | 右键 → 颜色 → 苔绿 | ✅ 走通；⚠ 菜单里是中文名，文件里是 `"3"`，agent 写的是 `#6ccda3` 之类 hex ⇒ **三种语言并存，没有一处能查到对应关系** |
| 5 | 标一个到期日 | 打字 `#due:2026-10-20` | ❌ 字进去了、屏上什么都没有（轴 3 的可见性为 0） |
| 6 | 把四格归成一堆 | 框选四格 → 找"成组" | ❌ 菜单里没有；退而求其次想**排布**：本轮已上（菜单"排布"9 条 + `Alt+A/H/D/W/V/S/J/K/L`），能排齐但排完仍是四格散着，没有容器 |
| 7 | 连一根线 | 找菜单、找键 | ❌ 完全没有（S6） |
| 8 | 关掉重开，东西还在吗 | 关窗口再开 | ✅ 在（自动保存）；⚠ 但屏上从不显示"已保存于几点"，他只能靠不丢来反推它存了 |
| 9 | 让 agent 帮我改这块板 | `outspread patch` | ✅ 0.4s 并进来、可撤销、正在拖的那格不被覆盖 —— 六条轴里最完整的一条 |

**结论**：新手能走通的是"记、改颜色、排齐、存下来、给 agent 读"；走不通的是"标记、归堆、连线"——恰好是这块板子从**记事**升级为**看板**的那三步。所以打磨顺序不是均匀撒，是先补这三条。

## 三、打磨清单（按"挡不挡住闭环"排，不按工作量）

| 优先 | 项 | 改哪一层 | 怎么算过 |
|---|---|---|---|
| P1 | **成组/拆组 + 两层选中**（第一次点必中组、第二次点中格、拖一格出界即脱组） | Core 的包含判定与选中层次函数 + 菜单/`Ctrl+G` | 死状态表里"归属"一栏变 ✅；界面自检加一条"造一个组→点两次→分别选中组与单枚" |
| P2 | **`#due` 色条 + 到期清单**（逾期红/今天琥珀，侧栏按日期排） | Core 解析（`DUE_RE`＋日期合法性）+ 渲染层 | 解析测试含 `#due:2026-13-40` 必须**不**认成到期、且要标出来；屏上色条由 shot 量像素 |
| P3 | **`#tag` 清单与筛选** | 同上 | 一格多标签、`#ff6b6b` 不算标签（把原型的 `HEXISH` 判据搬过来并测） |
| P4 | **空格子回收**（不变量 1） | 编辑器的取消路径 | 新建→Esc→`_document.Nodes.Count` 回到原值，且 `_history.UndoCount` 不变 |
| P5 | **连线**（贝塞尔＋四边中点＋右键拖端点＋`fromSide/toSide` 往返） | Core 的曲线与端点选择 + 渲染 | 导进导出逐字段核；端点把手命中 26px 过 WCAG 2.5.8 |
| P6 | **锁定与解锁** | 命令注册表的一条 | 锁上后所有搬动命令返回"这格锁着"，且解锁项永远在菜单里 |
| P7 | **颜色三语对照**（中文名 ↔ 预设号 ↔ hex） | 一张表 + 菜单文案带 hex | 校验器与菜单读同一张表；文档里能查到 |
| P8 | **保存回执**（状态条显示"已存 · HH:mm:ss"） | 保存路径 | 一次编辑后状态条出现时刻；不弹任何框 |

P1–P4 我按顺序做；P5 之后接回 port-parity 的 S6/S7。这份表里的每一条都必须是"改完有一发会抛错的测试"，不是文案。
