# 出口流程（每轮照做，不问、不提醒）

工具在 MCP `outspread_board` 下：`board_inbox` / `board_tickets` / `board_post` / `board_patch` /
`board_archive` / `board_read` / `board_tidy` / `board_shot` / `board_search`。
板子落在他最近打开的「Agent 出口」板（不填 `board` 就是它）。

## 0. 每轮开头：先对账（他改过的、新加的、@a 工单）

1. `board_inbox()` —— 列出「新 / 改 / 工单」三类的格子和编号。
2. 他写在正文 `---` 后面的那段话就是他的答复；`@a` 工单常存成 `@ta`（标签 a），**按字面找 "@a" 会全漏**，
   所以用 `board_inbox` / `board_tickets`，别自己扫字面。
3. 处理完再 `board_inbox(ack: true)` 把账抹平；不抹平，下一轮还会看到同一批。

## 1. 做完了就自己打勾

- `task` / `risk`：**事情确实办完**就打 `board_patch(id, done: true)`，凭据是本轮的闸门读数或实测数字。
- `decision`：**永远不替他勾**——那是他在表态，只有他点才变。
- 不许"留着等他验所以不打勾"：他 10-27 明确说过。验不了的部分单独说明，其余照勾。

## 1.5 他自己写的卡也要进组

`board_inbox` 报出来的「新」卡如果是他手写的（`@ta`／无 `@t`），按内容并进对应那一轮；
三张以上同类就单开一组（例：「工单 · 你提的五件」）。**绝不让他手写的卡散在板面上**——
他 10-27 的原话：「我新加的这几个为什么不加到分组里？我没有说过这些吗？」

## 2. 打勾之后必须归摞（他 10-27 的截图就是漏了这一步）

打完勾，把**每一个组**重新归档一次，已结的才会进摞：

```
board_archive(name: 原组名, into_group: 组编号, ids: 该组现有全部成员编号)
```

- `board_archive` 自己会分流：已结（`@b1` 或非红橙且勾过）→ 收成组内最窄最矮、叠成一摞；
  没结的 → 留在同一个组里、原尺寸平铺在摞下面。
- 编号必须是**整串 13 位**；喂截断的编号它会整发拒绝（这是故意的）。

## 3. 落一批新东西

1. `board_post(title, cards, round)` —— 一条一格，满行换行；组名自动带 `MM-dd HH:mm · 标题`。
2. 颜色：`decision` 红（1）＝要他拍、`risk` 橙（2）＝缺陷/没做完/值得告知，其余回答一律蓝（5）。
3. `board_tidy(gap: 48)` —— 整板横排、满行换行、按落板时间排，块间只留一条缝。**这活是 agent 的，别留给他。**
4. `board_read()` 回读，把「还欠几格」和格号写进汇报——**这是凭据**。
5. **顺带回读版面**：整板高、每行几块。连接器是长驻旧进程，`board_tidy` / `board_post` 的行为可能
   落后于仓里的代码（10-28 就把它 10-27 11:37 那份旧 exe 的单列收紧当成了横排，板子成了一条竖蛇）。
   发现不对：用新鲜构建的 `outspread-mcp.exe` 走 stdio 重排（同一份产品代码，换个进程），
   再 disable→重建→enable 把连接器本身换掉。

## 4. 写什么（判据只有一句）

**这条不需要他做什么、也不需要他知道，就别上板。** 叙述、过程、"我做了什么"、
**agent 自己的失误**都留在会话里；上板的只有：要他拍的、缺陷/没做完/值得告知的、待办、要他知道的结论。
他 10-27 原话：「这种废话不用告诉我，你告诉我有什么用呢？又不用我决定。」

**这一条现在是硬闸，不靠自觉**：`board_post` 里凡要挂 `@b0` 的三档（decision/risk/task），
正文必须有一行以 **`要你：`** 开头，写清他读完之后的下一步动作。没有那一行，整发被拒、盘上一个字都不写。

- 写不出「要你：…」的格子，就说明它不该上板 —— 说在会话里。
- `note`（结论）不挂 `@b0`、不占他的"还欠几格"，所以不受这一条管；但它是**要他知道的事实/读数**，
  不是我的工作日志。
- 来历：10-27 我落了两格"记我自己的待办 / 一条外推曲线"，都标着 @b0，他读完回的是
  「所以要我做什么？」「你又开始长篇大论…不用告诉我的就不用写在这里」。判据本来就在本文与
  AGENTS.md 里 —— 只写文档挡不住，所以装进了工具。

### 一格多长算长（他 10-28：「你又有在板子上长篇大论的趋势了，skill 没规定你要简洁回答吗？还是说没有例子？」）

**一格最多 4 折行（约 96 个汉字）＝一句事实＋一句「要你：…」**。这一条同样装进了 `board_post`，
超了整发拒绝。写不下就说明这格装了两件事，或装了一段过程：拆成几格，其余留在会话里。

- ✗「文字那一层占了平移 CPU 的一半（−20.7 点），而它只在两条路里选：A 合并连续同风格的行（一格里
  几行正文合成一枚 TextBlock，省元素、省字位，但必须证明逐字节相同才上）；B 收手，把它记成地板。
  要你：拍 A 还是 B。」——一句事实、两条路、一条附带条件挤在同一格。
- ✓ 两格：note「文字层占平移 CPU 的一半（−20.7 点）」＋ decision「A 合并同风格的行／B 记成地板。
  要你：拍 A 还是 B。」

## 5. 圆角规矩

- 一轮一个组；已结的组名后面加「（已结）」。
- 组与组之间不留半屏：收完紧、缝 48。
- 只在 `board_archive` 真的收不了（<2 格）时才让它平铺，并在汇报里说一句。
