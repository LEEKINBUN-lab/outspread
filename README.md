# 「铺陈」画板

一块无限画板：随手把文字和图片贴上去，自由挪动和缩放。板子存成 **JSON Canvas 1.0** 的 `.canvas` 文本文件，人和 agent 同时改同一份文件。

## 跑起来

```
dotnet build src\Outspread.Board\Outspread.Board.csproj -c Debug -p:Platform=x64
run-board.cmd            （或 src\Outspread.Board\bin\x64\Debug\net10.0-windows10.0.26100.0\win-x64\Outspread.Board.exe）
```

要 `Microsoft.WindowsAppSDK 2.5.1`（NuGet 缓存里已有）和 **Windows App Runtime 2.5.1**（已装则免安装直接跑；缺了会弹"缺少组件"）。工程是无包（unpackaged）配置：不打 MSIX，双击 exe 就能开。

开屏开哪块板：命令行给了 `.canvas` 就开那一块，其次 `TANKAI_BOARD`，再其次**上次最后打开的那块**；这台机器还没有记忆时开 `boards\快速入门.canvas`（教程板），连教程板也不在才走老的兜底搜索。记忆存在 `%LOCALAPPDATA%\Outspread\last-board.txt`，只是缓存：文件没了就退回首次开屏那条路。
**上次开着的那一排也一起回来**（`open-boards.txt`，顺序＝标签顺序；10-23 他要的——他开着教程板＋两块新板关掉软件，再打开只剩一块，其余标签凭空没了）。已经不盘上的那些不回来（改名搬走、空板关完即删），固定的「所有便签」永远排第一、不进这份记忆。

一次全验（构建 + 核心测试 + 界面自检；自检跑在 %TEMP% 的副本上，源是 `tests\fixtures\gate.canvas`，绝不动 boards 里的板子）：

```
check.cmd
```

## 手上的动作

| 动作 | 结果 |
|---|---|
| 拖动空白处 | 框选（Shift／Ctrl＋拖＝加选） |
| 右键拖动 | 平移（松手带惯性＝待做，见复刻契约 S4） |
| 空格（按一下，不带动作键） | 视图回到默认位置默认大小。焦点停在右下角按钮上也不激活那个按钮——这一发键归板子。**「空格＋拖动＝平移」10-24 撤了**（他点的就是这一下：空格只做复位，平移只留右键那条路）。**按住空格期间只要碰过板子**（框选、拖格、点一格都算），这一发就不算"按一下复位"——他报的"按住空格框选，视野跳了一下"就是那一发被框选用掉之后又去复位 |
拖一根线的端点（选中那格后端点上出现的小圆点） | 拖着的时候那一头**跟着指针走、画成虚线半透明**，并吸到离指针最近的那条边中心（半径按缩放归一）；松手：停在别的格上＝这一头改归属，停在本格另一条边上＝只换进出哪一面。10-24 他报"长按移动箭头时应该有个虚线或半透明的指示，不然都没办法确定自己是否成功抓住了"——原来确实是这样：按下只记一个状态，**中间屏幕上什么都不动**，抬起才换面 |
| 选中一枚 → 点操作条第四枚「连线」 | 进入拉线态：**先点的那枚是起点**，跟着指针那根就是成品同一套三次贝塞尔＋沿切线的箭头（不是直线）；移到另一枚附近时**四条边的中心会吸住**（半径按缩放归一，放大也粘得住），吸住的那条边亮一个圈；点下去即成链，方向写进 `fromNode`/`toNode`＋`fromSide`/`toSide`，终点那头戴箭头。点空白或 `Esc`＝这根线没画（未落定前一个字节都不动）。另一条入口照旧：双击某格的边缘从那一面起头。`Alt+C` 仍是"多选按叠放次序串成链"——它不指定方向，所以别拿它当连线的主路（10-24 他问"怎么决定谁被连接"，答案就是这条不明确，故加按钮） |
| 右键（没拖动的一按） | 只留板面上的事：叠放、删掉、回到 100%；「板子」「换板子」两节 10-23 撤了（归顶栏标签与 `Ctrl＋T/W`），配对／恢复／筛选搬到了标题条右端的 ⋮ |
| 滚轮 | 以指针为不动点缩放（5%–800%）。**每一发不再一跳 12%**：预览比例每帧朝目标走一小步（现读 8 发 burst 用 16 帧≈270ms 收敛，最慢一帧 9ms），点阵跟着这一帧那一档重画（5.7ms/发，与卡片同帧）——10-24 他点的"忽然放大缩小、没丝滑"就是原来台阶式跳变＋点阵冻在旧档、停手才啪地补一张。快速滚时仍只缩放整层（合成放大，字会暂糊），停手 120ms 才落一次真布局＋网格重绘（文字恢复清晰）——手势期间不排队等重排。**正在编辑那一格时这一发不缩放整块板子**：它把编辑框朝没露出来的那一头滚进视野（一格 48 屏幕像素，走到边就停）；已经全部看得见就明着说一句，不许悄悄什么都不做 |
| 点一格 / Ctrl＋点 | 选中 / 加选减选。**点组里的便签也只中那一枚**——组是一个关系，不是一块场地。**没过 4 像素的那一发算手抖**：只选中，一格都不许挪（10-24 他报的「单击偶尔轻微移动一下」；阈值与框选同一枚数） |
| 点组的名牌或边缘虚线 | 选中组里**所有便签**（按名单，不按场地；框自己不进选中）；从这两处拖＝整组一起走。组名牌画在框顶边**上方**，不再压在成员的字上 |
| 选中一枚便签 | 它左侧浮出三枚圆钮：**组 / 换色 / 删**。悬停 100ms 浮出一层 7.8% 的墨面、抬起 250ms 退去，按住再加到 12%（10-24 起状态是叠层带时长，不再瞬间换背景色，也不再没有按下态）。轻点组钮＝菜单（创建分组 / 移出分组）；**按住组钮拖**＝把这格拖进别的框（**一角碰上就亮蓝**，不用拖过中心线）或整格拖离现在的框（亮红）。松手时**格子留在原地不动，只有虚线框长过去罩住它**；光标带一枚淡环 |
| 单独拖便签 | 只挪位置，**不碰分组**：成员名单一个字都不改，框按名单长过去继续罩住它。**入组／出组只有按住组钮拖这一条路**（10-24 他把规矩定死了："普通拖动不能影响分组"）。旧的几何归属会吞人：新建一格落在框里当场长出分组、拖走一格把框拉长到把路上别人算进来——现在成员是一张名单，不是一块场地（写在组节点的 `members` 上，来历见 [docs/canvas-format.md](docs/canvas-format.md)《组名单写在哪儿》） |
| 把一格拖到另两枚以上**没归属的**格子叠在一起 | 松手那一拍格下浮「编成组？这 N 格」——点它就成组（走的是同一条 `Ctrl+G` 路）；下一次任何动作把它收掉。**已属别的组的不算进这一堆**（10-24：否则刚拖出去的那一枚会拉着老组员被罩成第二个框，一个组分裂成两个） |
| 双击组框内空白 | 在组里新建一格（新格中心落进框里就自动属于这组） |
| 拖一格 | 移动（8 像素内自动吸附边与中线，画参考线） |
| 排布命令（`Alt＋A`…`Alt＋L`）遇到组 | 一个组算**一件**：整组一起走，组内相对位置不变；选中的只剩一件时排它里面那几枚。那条框永远跟着成员重算——把一格挪出框，框就缩回来。**开板时也会先把有成员的组框贴回成员包围盒**；没有成员的组不画虚线框 |
| 端角那 8 个方块 | 缩放；多选时缩放整组 |
| 双击空白 / 双击一格 | 新建并进入编辑 / 改这格文字 |
| 在便签里换行 | 编辑框随内容长高，不用等提交；提交后卡片按正文定高。**手动拖过手柄的便签保持你给的框**，不再被自动高度改（标记记在 sidecar 的 `manualSize`） |
| 便签装不下 | 右下角出现「更多 ↓」；往下翻后左上角出现「↑ 更多」。滚轮停在这一格上时按行翻，不缩放整页。**把框拉高到全部放得下，窗口自己回到顶、牌子收掉**——不许出现"底下空着还挂更多" |
| Ctrl＋C | 复制选中的那几格（全选就是整块板子）。**贴到别的标签页里也在**：颜色、大小、相对排布、组框、线头一起带走，图那张格子的字节从原来那块板旁边搬进这块板的 `assets/`；同一份片段贴两遍＝两套名字（第二遍撞上自己会另铸），撤销两发交回原样 |
| Ctrl＋V | 先认刚复制的那几格（见上一行）；那不是片段，才去贴剪贴板里的文字、图或文件 |
| 从资源管理器拖入 | 图片进 `assets/`，别的按链接放 |
| Delete · 操作条那枚红垃圾桶 | 删掉选中的（可撤销）。淡出那一发**连选中框、八枚手柄与操作条一起收**（167ms）——只淡卡片、把那几层留到最后一拍忽然消失，读起来就是「东西没了但套子还在」（10-24 他点的） |
| 选中 2 格以上按 Alt＋C | 连成一条链（按叠放次序串）；再按一次拆掉。箭头画在纸底下，末端按切线收口 |
| 鼠标移到卡片左下角那排牌子上 | 长出 ×，点一下＝把这条日期／这个标签从正文里拿掉（可撤销）。牌子分两种：**日期＝一个状态点＋文字，没有盒子**；**标签＝无描边胶囊**（淡底一档）。为什么不是方框，调研与来源在 **[docs/research-chrome-and-properties.md](docs/research-chrome-and-properties.md)** §二·6 |
| Ctrl＋Z / Ctrl＋Y | 撤销 / 重做（包括"并入外部改动"这一步） |
| Ctrl＋0 · 右下角 `− 100% +` | 缩放；点中间那个比例＝回 100% |
| 标题条右端的 ⋮ | 设置菜单：**配对手机… / 恢复… / 筛选：日期与标签…**（浏览器式、带图标；10-23 从右键菜单搬来）。`Esc` 收起 |
| 设置菜单里的"筛选：日期与标签…" | 打开筛选面板（原来那枚漏斗按钮按他的意思删了）。筛上了以后板顶才出现一条窄横幅（「只看 #周会 · 15 格中的 1 格 · 点这清除」），点横幅＝清除；平时板子上不常驻任何东西 |
| 筛上以后，组里没命中的那几格 | **折到命中的那一格背后**，框跟着收成看得见的那几格；横幅会说"几格折进了组"。鼠标移到这一组上（框或接住那格都算门）就摊开，摊开时它们仍然压暗、框回到全组；手移开折回，`Esc` 先收这一层。折叠只在画面上，**文档一个字节不写**；折进去的格子点不到，要拖它得先摊开 |
| 按住 Tab | 键位清单，松手就收起（点它空白处也收起）。**第一下就开**（不在编辑框/浮层里时），不用先点一下板子。10-23 换成宽裕两栏：760 宽、内缩 16、栏距 56、圆角 12，两栏各 15 行；窗口更窄时整张页跟着收。**同一日他把 Tab 的"通用找按钮"（平台焦点遍历）屏蔽了**：归不了板子的那些场合（编辑框、改名框、浮层）按 Tab 什么都不做，焦点不再跳到别的控件上——代价是键盘走不了控件环，这块板子按鼠标用 |
| 顶上那条标签：点一枚 | 切到那块板（一块板一件事）。**活动标签填成板底色**，只圆上沿；非活动标签的 × 只在悬停时出现。× 压在标题右侧那格留白上（不占宽度、悬停只切透明度）；**标签宽度与鼠标无关**——10-24 实测到那 4 个像素其实来自模板的「× 显／× 藏」两组状态各换一档右内缩（上游默认 4 与 8），要把它压平必须在 `App.xaml` 的合并字典里覆盖那两档（设在 `TabView` 自己的 Resources 上取不到）；自检拿长名字正对照量三档相等，长名若还贴着 82 下限就直接报「正对照没成立」；**× 钉在标签最右侧**，名字再短也不跟在字后面（10-24 他点的；表头自己至少撑到最短那一档标签的内宽）。最后一块不给关：按它的 × 只会告诉你为什么 |
| 右键一枚标签 · 双击一枚标签 | 重命名（就地变成输入框，Enter 提交／Esc 取消／**点到别处也提交**；改名途中那一枚的宽度钉住不变）· 关闭 · 关闭其他。双击标签同样直接进改名，不会再最大化窗口 |
| 标签条上的 ＋ · `Ctrl＋T` | 点一下直接建一块 `未命名板1`（1 被占了才按 2、3…顺延），**不再弹名字框**；名字随时右键改。加号紧跟最后一枚标签（30px、圆形悬停、十字是画出来的，比标签文字的光学中心低 2px），新标签从落帧那一刻就带着名字 |
| 右键加号 | 新板块（“打开盘上的板子”已撤：盘上的板子不再从菜单里翻） |
| `Ctrl＋W` · 标签上的 × | **关掉一块＝从本机删掉这块板**：`.canvas`、相机 sidecar、这块板自己的历史快照一起删（命名板也一样）。最后一块不给关——先 `Ctrl＋T` 起一块再关它，窗口不会落到没有板子的状态。同步账本保留（同名板下次同步时用它把删除推过去），远端仓库那份不在这一下里 |
| `Ctrl＋PageDown` / `Ctrl＋PageUp` | 在开着的几块板之间走 |
| `Alt＋P` | **演示模式**：一枚组就是一页，页序＝组名里的时间戳（一轮一组的板子翻起来就是时间线）。进入收起标签条、徽章与小地图并转全屏，相机滑到那一页；`←/→`、空格、翻页键翻页，`Home/End` 跳首末页；指针或滚轮一动就接管（可以边演边改）；`Esc` 退出并还原进来的相机与界面 |
| 窗口外观 | 无框；窗口后面有一层**自绘轻投影**（约 18px 软边、峰值约 13% 黑），最大化/最小化时不画。它是独立的 click-through tool window，不进 Alt+Tab/任务栏 |
| 在标签条的空白处拖 | 移动窗口——那一条就是标题栏（系统那三枚按钮让出 138 像素） |
| Esc | 先收眼前那层浮层，再清选中 |

编辑文字时：`Ctrl＋Enter` 或点到别处提交，`Esc` 放弃。

给一格标日期或标签：**正文里单独占一行**写 `@d2026-10-20 @t周会`（只有这一种写法；`#` 已经让给 markdown）。卡片上这行字不出现，换成左缘一条色条和底下一行读数（`逾期 10-20 · #周会`）。为什么不是字段、行内为什么不算，都写在 **[docs/canvas-format.md](docs/canvas-format.md)**。

## agent 怎么读这块板

格式与约定在 **[docs/canvas-format.md](docs/canvas-format.md)**。命令行：

```
outspread list / show ID / add / patch ID / rm ID / validate / shot
outspread sync link / status / once / forget
dotnet build src\Outspread.Cli\outspread.csproj -c Debug
src\Outspread.Cli\bin\Debug\net10.0\outspread.exe list
```

板子按 `--board` > `TANKAI_BOARD` > 向上找 `boards/scratch.canvas` > 本目录第一个 `.canvas` 定位；都找不到时落到 `%LOCALAPPDATA%\Outspread\boards\scratch.canvas`。**界面比这一条多两步**（上次打开的那块 → 首次开屏的教程板），CLI 不读那份启动记忆——agent 要指哪块就显式给 `--board`。

界面开着时，外面改了文件会在 0.4 秒内并进来（只并入对方改的那些格，不覆盖你正在拖的那格），并且这一步可以撤销。`outspread shot` 向**运行中的界面**要一张 PNG（`--mode view|fit|node|chrome`，可带 `--select 节点,节点` 把选中态画进去、`--panel filter|cheat|rename` 把那几层打开来拍，拍完都恢复原样；`--panel rename` 只预览行内输入框，不提交改名）；没有开着的界面就明确报错，不会自己另画一份。

## 手机 ↔ 电脑同步

板子的**跨端副本**放一个私有仓库（现在：`LEEKINBUN-lab/tankan-boards`），只用平台的"按路径读写单文件"HTTPS API 搬——**不装 git、不装同步软件、不买服务器**。`.canvas` 本体仍是纯 JSON Canvas 1.0，同步元数据一律在外面：远端多一个 `boards/.sync/<名字>.manifest.json`，每台设备自己在 `%LOCALAPPDATA%\Outspread\sync\` 存**上次大家一致的祖先全文**。

为什么要祖先：格式的规范里**没有任何版本／时间戳字段**，两份文件放在一起没法从内容判"谁新"。所以"谁新"靠远端文件的一次性令牌（写的时候带上你读到的那个，被人抢先就失败重和），"怎么合"按 `id` 逐格逐字段判。

```
outspread sync link --remote owner/仓库名 --token-stdin   （令牌进 Windows 凭据管理器，不进仓、不进文件）
outspread sync status [--json]     读数：rev / 远端令牌 / 待发几块 / 上次为什么没成 / 冲突副本
outspread sync once                拉—合—推一轮（界面的触发点：存盘后、回前台、每 8 秒，失败退到 16→120 秒）
outspread sync pair                把手机要的配对载荷画成二维码，只出现一次；窗口太窄会明说而不是画半张
```

图片**只搬被某一格引用的**：`assets/` 里没人指的孤儿图不上云（那是 `AssetStore` 对孤儿的一贯态度——报告，不删）；单张超过 1 MiB 的会被点名拒发，其余照走；板子引用着而两头都没有的图，会被说成"那一格会空着"。空转一轮实测**只发 1 个请求**（一发树，稳态不读任何文件）；那发带 `If-None-Match`，304 不计入 5000/小时的限额（实测 `remaining` 不动），所以 8 秒节拍在稳态是 0 配额，只有远端真的变了的那轮才计。

三条要记住的行为：**首轮两端取并集**（没祖先时删除无法判定，所以谁都不清空）；**内容双改不隐形取胜**（远端那半留在原格，本地那半另起一张落在原格下方，并在日志里留一条判决）；**挤不进去就一个字节都不动**（三轮都被挡 ⇒ 本地保持原样，本想上传的那份整份写在旁边的 `<板子名>.canvas.conflict-<设备名>-<yyyyMMdd>-<HHmm>-r<N>`）。

**改名只动本地文件名**（文件与 `.canvas.view.json` 一起走，watcher／shot／同步按新路径重绑）。同步开着时，远端会把新名字当**另一块板**再发一份，旧名那份留着不动——这轮没有做远端迁移，回执里会明说。

契约、真机读数（含平台返回码的确切形状）和"哪些格子没测到"在 **[docs/sync-contract.md](docs/sync-contract.md)**——安卓端要照那一页复刻，裁决规则两份实现必须逐字一致。

## 日志

失败原因默认写到 `%LOCALAPPDATA%\Outspread\board.log`（`TANKAI_DIAGNOSTICS=<路径>` 改位置，`=0` 关掉）。屏上不显示任何自证性文字。
