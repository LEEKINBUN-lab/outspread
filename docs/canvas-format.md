# `.canvas` 这份板子的读法与写法

给 agent 看的契约。这里写的每一条都对应代码里的行为，不是愿望。

## 是什么

一块板 = 一个 `<名字>.canvas` 文本文件 ＋ 同目录的 `assets/` 文件夹。
文件就是 **JSON Canvas 1.0**（规范：<https://jsoncanvas.org/spec/1.0/>，仓库 `obsidianmd/jsoncanvas`，MIT）。Obsidian 能直接打开同一份文件。

- 顶层只有 `nodes` 和 `edges` 两个键是本程序认识的；**其它顶层键、其它未知字段一律原样保留**（读写都保留，不会在下次保存时丢掉）。
- 缩进 2 空格、**LF 换行**、UTF-8 **无 BOM**、中文按字面写（不转 `\uXXXX`）。
- 几何字段写成整数。

## 节点

必填：`id`、`type`、`x`、`y`、`width`、`height`。`type` ∈ `text` / `file` / `link` / `group`。

| 字段 | 用在哪 | 说明 |
|---|---|---|
| `text` | text | 正文。换行在 JSON 字符串里是 `\n` |
| `members` | group | 成员 id 的数组（便签的 id，或另一个组的 id＝嵌套）。**规范里没有这一项**，来历与退回规则见下面《组名单写在哪儿》 |
| `file` | file | **相对板子文件**的路径，如 `assets/img_a1b2c3d4e5f6.png` 或 `attachments/<hash>_<名字>`。不许绝对路径、不许 `..`，否则报"outside the board folder" |
| `url` | link | 链接目标；`file:///…` 是放在别处的本机文件/文件夹，`http(s)://…` 是网页 |
| `label` | group、file、link | group 是规范里的标题；file/link 上的 `label` 是本程序扩展，只存卡头显示名，不存长路径 |
| `text` | text、file、link | text 是规范正文；file/link 上的 `text` 是本程序扩展，作为卡片正文 |
| `entity` | file、link | 本程序扩展：`file` / `folder` / `web`，决定卡面怎么认；丢了也能从 `url` 与盘上形状退回 |
| `table` | text | 本程序扩展：从 Excel 粘贴的表格结构（合并、底色、列宽）；同一格的 `text` 同时写一份 Markdown 兜底 |
| `note` | text（带 `table` 的那一格） | 本程序扩展：表格**下面**那几行补充文字。表的结构走 `table`＋`text`，备注走这一格，两路互不覆盖 |
| `color` | 任意 | `#RRGGBB`（也接受 `#RRGGBBAA`，alpha 被丢弃）或预设 `"1"`–`"6"`。不写 = 跟随深浅色主题 |
| `background` / `backgroundStyle` | group | `cover` / `ratio` / `repeat` |

**叠放次序 = 数组顺序**：数组里第一个在最底下，最后一个是最高。新增的格子追加到末尾（也就是最上面）。

`id` 的约定：`u` ＋ 12 位小写十六进制 ＝ 界面在人手拖动时铸的；`a` ＋ 12 位 ＝ agent 或命令行铸的。前缀就是两个写者不撞车的机制。**别的形状（例如 `hypothesis-a`）也收**，只是会得一条提醒。重复 `id` 是硬错误：文件直接拒绝打开。

## 组的框是派生的

规范里 group 只有一个矩形，**没有成员表**，所以归属是几何的：一张便签属于"中心落在哪个框里"的那个框（嵌套时取最内层）。

在这个前提下，界面把框当成**派生量**，不是可以单独摆动的东西：

- 框永远等于"它那些成员的包围盒外扩 10 世界像素"（`Grouping.Enclose`）。每一步（拖动、排布、排列、改色）结束时重算一次，所以框不会留在成员后面。
- 只重算这一步真的改变了派生值的那些框：一次改颜色不会顺手搬走与它无关的框。没有成员的框保持原样（不凭空缩成一点）。
- **排布命令里一个组算一件**：整组一起平移，组内相对位置不变。选中的东西只剩一件时退到"排它里面那几枚"（一件东西没法对齐自己），所以"点一下组再按左对齐"排的是组内那几枚。
- **成员是一张名单，不是一块场地**：组框上写着 `members`（成员 id 的数组），谁在组里只看这张表。普通拖动一格**不改这张表**（那是挪位置，不是改关系），所以把它拖到框外，框会长过去继续罩住它；入组／出组只有按住便签左侧那枚组钮拖这一条路，外加**双击框内空白＝直接在组里建新格**（名单写进去、框长过去罩住——10-31 他拍的；这是显式动作，与 10-22 那个"落在框里就莫名其妙入组"不是一回事）。10-24 他点的两格 bug 都出在旧的几何归属上：新建一格落在框里当场长出分组、拖走一格把框拉长到吞掉路上别人。
- **名单里也可以写另一个组的 id（11-12 起的嵌套分组）**：那个组整块算外层组的成员，外层框按内层框的派生包围盒再包一圈；点外层名牌选中里面**所有**便签（子组一路走到底），点内层名牌只选内层；拆外层只删外层，内层组连同它的名单留下。外层框画淡一档，层级一眼看得出来。名单写成互相装着的环时，读的那一侧会把环拆开（按框的文档顺序），画面上不会出现互相包着、量不完的两只框。
- **组钮拖入的警示态（进＝蓝、出＝红）只活在手势期间**：正常松手与指针被打断（取消、捕获丢失）都要一发清干净，任何框都不许亮着过夜。
- **筛选时组里没命中的那几格折到命中的那一格背后**：框跟着收成"看得见的那几格"的包围盒，鼠标移到这一组上就摊开（摊开时框回到全组，那几格仍然压暗，因为它们没命中），移开折回，`Esc` 先收这一层。折叠**只长在画面上**——一帧位移与透明度，文档一个字节不写：筛选把三格并到一处的样子要是写回文件，一次筛选就把便签的"真位置"同步给了手机。

对 agent 的后果：想让某格属于某个组，就把它的 id 写进那个组的 `members`；**只改 `x`/`y` 不改变归属**（那是 10-24 之前那套几何归属的写法，现在只有没名单的框还吃它）。想让框好看，写成员坐标，别手写框的 `x/y/width/height`——框是派生的，每一步结束都会按名单重画。名单里指向已经不存在的格子的名字，读的时候会被丢掉。

## 组名单写在哪儿（规范里没有怎么办）

**规范里的 group 只有 `label`、`background`、`backgroundStyle` 三项，没有成员字段**
（<https://jsoncanvas.org/spec/1.0/>，10-24 现读），而且规范对未知字段没有任何前向兼容承诺——
和本仓对 `tags`/`due` 查过的是同一句答复："No rule stated"。

那为什么这一次选择加字段，而不是像日期与标签那样把名单藏进某个规范内的字符串？

- 藏进 `label`：那是**给用户看的组名**，界面上要显示、要能双击改名，把 id 混进去等于让名字变成机器话。
- 用 `edges` 连"组→成员"：规范内、别的工具也认，但别的工具会把这些边**画成箭头**压在板子上，
  而我们自己还得把它们藏起来——一份数据两种读法，谁都没赢。
- 继续用几何：那就是他这次点名的两格 bug 本身，不是取舍。

所以写成一份**未知字段**，并把最坏情况说清楚、也留好后路：

| 情况 | 这份程序怎么做 |
|---|---|
| 框上有 `members` | 名单说了算；**这个框不再靠几何收人**（新建在框里、拖进来一格都不改归属） |
| 框上没有（别的工具写的、10-24 之前存的） | 退回几何：中心在框里就算成员；开板时把这一刻的成员抄成名单，从此按表走 |
| 被不认识它的程序重写一遍（字段丢了） | 最坏是退回上一行的几何语义，**不丢内容**：格子、正文、颜色、框都在 |
| 名单里有已经不存在的 id | 读的时候丢掉，不在别的节点上留鬼名 |
| 名单里写着另一个组的 id（嵌套） | 那个组整块算成员；互相装着的环在读的那一侧按文档顺序拆开 |

一次性的迁移会在他这边留下什么：开一次板，那块板上每个旧组会多出一行 `members`，
并因此多一次存盘（走的是既有的"框归位就存"那一路），同步会推一次。只有带旧组的板子会这样，一次而已。

## 日期与标签写在哪儿


**规范里没有 `tags`，也没有 `due` 字段**（1.0 的 text 节点只允许 `id,type,x,y,width,height,color,text`），而且规范对未知字段**没有任何前向兼容承诺**——查过，答复是"No rule stated"。这份文件同时被界面、安卓端和 agent 读写，所以"加个字段"等于把数据交给别人的未定义行为：被忽略一次就是丢一次。因此这两个标记写在 `text` 里，用一种不会撞车的形状，**单独占一行**：

```
@d2026-10-20 @t周会
交周报，带上上次的读数
```

只有这一种写法。`@d` 后面直接跟值，到下一个空格为止；一行里可以并排几枚。

- `@d` 的日期接受三种写法：`@d2026-10-09`（整年）、`@d27-1-1`（一到两位年份＝20xx，即 2027）、`@d12-04`（不写年份＝今年）。`-` 与 `/` 两种分隔都认（`@d2026/10/9` 与 `@d2026-10-09` 是同一个日子），键名不分大小写。不写年份那一档用的是**这块板当天的年份**（界面把视图的 today 传进解析），所以它与卡面的"逾期／今天／将来"永远同一口径。
- 一行里想给多个标签就写多枚 `@t`：`@t周会 @t急`。**一枚 token 就是一枚标签**——`@t周会、急` 是一枚叫"周会、急"的标签，不是两枚（拆开会变成"删一个牌子带走两个"）。
- **一行必须整行都是 token**，混在句子里的 `@d…` 不算属性。这条限制是为了不让"讲这套写法的那一格"把自己的例子吃掉；不算数的 token 也**照样显示在原处**，不是静默丢弃。
- 界面上属性行不出现，卡片底下换成一行读数（`逾期 10-20 · #周会`）＋ 左缘 2px 色条；进入编辑时原文照见（写的就是存的），可以直接改。
- 日期必须是真实日子。`@d2026-2-30` 会被标成"日期读不出"（画红边）而不是被悄悄调成 3 月 2 日。
- `@n3` 是序号，卡面左下角画成 **NO.3**；`@n` 后面不是数字（`@nfoo`）就不算标记，那一行照旧是正文。
- 完成状态**进筛选那一档**：面板里「完成」两行——**已完成**（只放过 `@b1`）与**还没做完**（放过 `@b0` **和压根没写 `@b` 的**：待办板上"没写"就是还没做完，单开一档"无标记"会把整块板筛成空白）。再点同一行＝取消；横幅写清是哪一档、筛掉多少。筛选三档（标签／日期／完成）都是视图状态，**不进 sidecar、不进撤销**。

- `@b1` 已完成、`@b0` 未完成，左下角画成「已完成／未完成」那枚牌子。**它是这排牌子里唯一的一枚开关**：点牌子本身＝在 `@b0`↔`@b1` 之间切换（不进修改态），点牌子右侧的 × 才和其他牌子一样——把这段从正文里拿掉＝这块便签不再有这个字段。只认 `0`/`1`：`@b2`、`@b` 都不算标记，那一行照旧是正文。改的是 `text` 里那两枚字符，所以 agent 与手机写 `@b1` 就够了，不需要任何新字段。
- **`#` 已经不是标记语法**，它归 markdown：行首 `#` 是标题，`#周会` 写在正文里就是这三个字。旧式 `#due:2026-10-09`、`#周会`，以及旧长式 `@due(2026-10-20)`、`@tag(周会)` **都不再被读取**，也一律不从卡片上摘掉——写了旧式的人会直接在卡面上看见自己写的那串字，而不是被告知"你写的日期读不出"。牌子上的 `#周会` 那个井号是**显示名**，不是语法。

## 这块板子会忽略什么

- **`edges` 不画**，但读进来原样留着、写回去不丢。你写了连线，板面上看不见。
- **`group` 是一层虚线框，不是一张卡**：它画自己的 `label` 当名字，不加底色、不加班底影子（把它当卡片画会在板上盖出一块 620×300 的实心板，第一版迁移就是这么错的）。成员按几何包含现算，规范里也没有成员列表。
- **没有旋转**。规范里没有这个字段；文件里出现 `rotation` 会得一条"kept in the file but ignored on screen"的提醒。
- 便签字号不在格式里，存在旁边的 `<名字>.canvas.view.json`（见下）。

## 那个 `.view.json` 是程序自己的

`<板子名>.canvas.view.json` 存相机（`panX`/`panY`/`zoom`）、每格字号、`noteSize`（`auto`＝便签高度随文字走，`fixed`＝改字不动框高，尺寸只归手柄），以及 `manualSize`（被用户拖过手柄的文字格 id；自动高度跳过这些格子）。**它是本程序私有的，默认 .gitignore，agent 不要改**：改了不会报错，只会被下次存盘覆盖。格式里没有的东西我们不塞进 `.canvas`，这样这份文件对任何兼容工具都还是干净的。

同步开关也在这里：`"sync": false`＝**这台设备**不把这块板推上远端（窗口与 `outspread sync once` 都拒发；`outspread sync off --board 路径` 打标记）。性能/回归那种几百格的测试板必须用它挡在仓外（或干脆放 %TEMP%，那里的板本来就同步不了）。没这枚字段的板照常同步；标记是设备本地的，远端与别的设备不知道。

**`noteSize: auto` 意味着"打开这块板"可能会改写 `.canvas` 里的高度**：载入与外部并入这两发都会按当前的文字重算一遍（`fixed` 档与 `manualSize` 里的那些格子不碰）。所以 agent 只改 `text` 不加高度是**对的**——框会自己跟上；反过来说，别指望盘上那份 `height` 就是屏幕上的那一格。被压到装不下的时候，正文最后一行淡进**正文区的下沿**就停：左下角那排牌子（日期、序号、标签）是常驻件，**永远不被渐隐盖住**。

## 图片怎么落盘

`assets/img_<内容 sha256 前 12 位>.<真实扩展名>`。同一张图粘两次还是一个文件。
扩展名按字节实际是什么写什么（JPEG 不会改名成 `.png`），也不重编码 —— 一张照片转 PNG 大约要胖五倍。

## 文件、网页与表格卡

卡面上**只有牌子**：「原件副本」「链接原件」「本板文件」「网页」「找不到」加一枚圆点，不再补一行"副本在本板·删卡移到回收站"这类来源说明，也不在卡上写警示长句。**每枚牌子的含义收在牌子里**：指针停在牌子上出原生 tooltip（例如「原件副本」＝*根据原文件创建的副本；删掉这张卡时，这份副本一并移到回收站*，「链接原件」＝*只放链接，原件还在原处；原件被移动或删除后这张卡会失效*）。

拖进来或粘贴进来的非图片文件按大小分两种走法：

- **≤ 10 MB**：副本写进 `attachments/<内容 sha256 前 12 位>_<原文件名>`，节点是 `file`，牌「原件副本」。删这张卡（或整块板）时，只有没有任何卡再指它的副本会移到系统回收站；同一内容被两张卡共用时，删一张不动文件。
- **> 10 MB**：先问一句「收纳到本板 / 只放链接 / 跳过」。选「只放链接」时节点是 `link`，`url` 写成 `file:///…`，牌「链接原件」；删卡只删卡，绝不碰原文件。
- **按住 Ctrl（或 Shift）放下**＝切换到链接型：一件都不复制，也不再询问，全部按「链接原件」落卡。拖动途中跟指针的那枚模式牌会实时写明当前是哪种（放到板上／只放链接／放不下）——系统自带的拖拽气泡画在文件正中，盖住拖的东西，不用它。
- **收纳读不出原件**（正被其他程序占用、没有权限）：拒建并点名，回执只写「N 个文件未建卡：文件名」，原因只进日志（2026-10-31 他拍的：回执要短）。
- 文件夹永远只链接（`link` + `file:///…`，牌「链接原件」），不复制整棵目录树。里面有图片/视频时，卡头下面给一排**缩略图**（最多四格，视频取 shell 缩略图，取不到留一枚播放符号），不再列子项名字。
- 单独一行网页地址粘进来会认成 `link` + `entity: web`，卡面只存标题与域名，**不抓快照**。

**三条创建入口**（走的是同一条识别逻辑，所以粘贴与菜单不可能认得一宽一窄）：

- **拖进来**：从资源管理器把文件或文件夹拖到板面。
- **`Ctrl+V`**：在资源管理器里复制后粘（那是"文件项"，不是文本）；或者粘**一行**文本 —— `https://…`／`www.…` 建网页卡，`D:\资料\方案.pdf`、`D:/资料/方案.pdf`、`\\nas\共享\x`、`file:///D:/…`、以及被双引号包住的那几种（资源管理器右键「复制文件地址」给的就是那种）建路径卡。混在句子里的、或占两行以上的，一律当文字便签。
- **右键空白 → 从路径或链接新建卡片**：弹框里粘一行或打一行，按「建卡」。认不下时**框不关**，原因写在框底下（"这个位置不存在"、"既不是网址也不是一行绝对路径"都算）。在网页上选中链接文字→右键「复制」也认：所选文字是一行短标题、且那段 HTML 里只有一条 http(s) `href` 时，取那一条地址。

**位置不存在就拒绝建卡**：回执点名是哪一条，板上一格都不留 —— 留一张戴「找不到」牌子的空卡，等于把一次粘贴变成要人回头清的垃圾。「找不到」那块牌子仍然留给"建好之后原件才被移走或删掉"的卡。

第一行只留三样：一枚类型形状、文件名、牌子。第二行（大小·时间，以及**打开**与**在文件夹中打开**两枚动作）平时藏着，位置永久占着 —— 指针移进这张卡才淡进来，卡的高度一格都不变（自检拿这条当尺：淡入前后卡头高度必须相等）。网页只有「打开」；键盘和触屏走右键菜单里的同名两项。形状逐字取自 [microsoft/fluentui-system-icons](https://github.com/microsoft/fluentui-system-icons)（MIT）的 `ic_fluent_*_20_regular.svg`，运行期自己吃那段 SVG 路径（这版投影没有 `Geometry.Parse`，`SvgImageSource` 也没有同步入口），认不下来就退回文字，不画半截。这台 Win10 没有 Segoe Fluent Icons，同一码位在两枚字体里画出来的东西不一样，所以不走图标字体。

`attachments/` 里的文件仍走 `AssetSync`，但 GitHub Contents API 单文件上限是 1 MB；超过的文件会在同步报告里按名字拒绝，本机卡照常能用。这是当前跨设备边界，不是本地丢文件。

表格粘贴优先读剪贴板 HTML，退到制表符文本；结构写进 `table`，`text` 写 Markdown 兜底。渲染统一居中、用板内字体；合并单元格、底色与列宽比例保留，公式只保留粘贴时的显示值。**表格卡不戴卡头**（没有"几列几行""粘贴自 Excel""XLS"这些字样）：双击某一格就地改那一格，回车收下；卡片下面留一行字的位置，双击补进去的是 `note`。改完一格，`text` 里那份 Markdown 会跟着重算。

## 同时改同一份文件

写盘走命名互斥 `Global\outspread.canvas`，写临时文件再原子改名。界面和 `outspread` 用同一把锁。

**存盘是打补丁，不是整份覆盖**：界面上保存的只是"人改过的那几格"，所以你和界面可以在同一秒各写各的，谁都不会把对方抹掉。反过来说：**你用 `outspread` 改的时候，也只该改你点名的那些字段**。

界面开着时你改了文件：0.4 秒内并进来（只应用你改的那些格；如果它正在被你拖或正在编辑，那一次改动会等你松手）。并入这件事本身是一条可撤销的历史，标签写作"并入外部改动（N 处）"。
你把文件改成解析不了的样子：界面**保留当前画面、拒绝覆盖**，并在状态栏说明原因 —— 不会把你的工作冲掉，也不会假装读到了。

## 命令行

```
outspread list [--board 路径] [--json]
outspread show ID [--board 路径]
outspread add --text 内容 | --text-file 文件 | --file assets/x.png | --url 链接 | --group 标题
           [--x 0 --y 0 --width 260 --height 90] [--color 3] [--id 自选]
outspread patch ID [--x --y --width --height --text --text-file --file --url --label --color] [--clear color]
outspread rm ID
outspread validate
outspread shot --out 图.png [--mode view|fit|node|chrome] [--id 节点] [--select 节点,节点] [--panel filter|cheat|banner|rename]
```

`--select` 与 `--panel` 都是"拍完就恢复原样"：前者把选中态画进这一张再收回原选中集，后者临时打开那几层（右下角的筛选面板、按住 Tab 的键位清单、只在筛选激活时才出现的板顶横幅——`banner` 会真的上一副 lens，拍完交回你原来那副；`rename` 把当前标签换成行内输入框，**只预览不提交**）再按开之前的状态收起。浮层从 `Popup` 搬进了界面自己的视觉树，就是因为这一发拍得到——不然"圆角 8、透 94%"只能靠嘴说。

长文本用 `--text-file`：多行内容塞进命令行会被引号规则吃掉一半。

退出码：`0` 成；`1` 有校验错误或答复说没成；`2` 用法错；`3` 文件本身读不懂；`4` 读写失败；`5` `shot` 时没有开着的界面；`6` 管道中途断了。

## 校验器会说什么

硬错误（拒绝打开）：根不是对象、`nodes` 不是数组、节点没有 `id`、两个节点同一个 `id`。
其余是提醒，板子照样能开：颜色不是 `#RRGGBB`/`"1"`–`"6"`、`file` 指向板子目录外、link 没有 `url`、edge 缺字段或指向不存在的节点、`id` 不合前缀约定、出现 `rotation`、以及**底色和两种墨水都够不上 4.5:1 对比**（比如 `#7F7F7F` 只有 4.2:1 —— 颜色是你的内容，我们不偷偷改，但会说出来）。

`outspread validate` 把这些逐条打出来，有错误时退出码 1。
